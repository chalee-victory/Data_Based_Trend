# 대시보드 추가 기능 — 동적 인사이트 패널

기존 `DASHBOARD_SPEC.md`에 이어붙이는 추가 스펙입니다. Claude Code에 "이 내용을 대시보드에 추가해줘"로 전달하면 됩니다.

## 목적

필터(역 선택·기간·지표)를 바꿀 때마다, 그 조건에서 실제로 무슨 일이 있었는지를 **자동 계산된 문장**으로 보여준다. 정적인 설명 텍스트가 아니라, 현재 필터 상태를 입력으로 매번 다시 계산하는 것이 핵심이다.

## 화면 위치

메인 차트 바로 아래(또는 우측)에 카드 형태로 배치. 필터가 바뀌면 즉시(디바운스 200~300ms 정도) 갱신.

## 표시할 인사이트 (조건별 로직)

### 1. 기간 내 전체 변화율 (역 1개 선택 시 항상 표시)
선택 기간의 시작 3개월 평균 대비 끝 3개월 평균으로 계산.
> "판암역은 선택한 기간(2017-01~2019-12) 동안 총 **+9.2%** 변화했습니다."

### 2. 구간 내 최대 변화 시점 자동 탐지

### 3. 여러 역 비교 (2개 이상 선택 시)
선택된 역들의 기간 내 변화율을 비교해 최고/최저를 자동 언급.
> "선택한 5개 역 중 **판암**이 가장 강하게 성장(+9.2%)했고, **대동**이 가장 크게 감소(−15.4%)했습니다."

### 4. 시스템 평균 대비 (잔차 지표 선택 시, 또는 항상 보조로)
해당 역의 기간 내 평균 잔차값을 보여주고, 방향을 해석.
> "판암역은 이 기간 동안 22개 역 평균보다 **+3.1%p** 더 좋은 흐름을 보였습니다."

### 5. 팬데믹 구간 포함/제외에 따른 차이 (팬데믹 토글과 연동)
같은 역·같은 지표를, 팬데믹 구간을 포함했을 때와 제외했을 때 변화율을 둘 다 계산해서 대조.
> "팬데믹 구간(2020-01~2022-06)을 포함하면 변화율은 −18.3%지만, 제외하면 +4.1%로 달라집니다 — 이 역의 장기 흐름은 팬데믹 영향이 컸다는 뜻입니다."

### 6. 축 모드 전환 시 안내 문구 (교육적 요소)
"공유 축 → 역별 자체 축"으로 전환하는 순간, 왜 다르게 보이는지 짧게 안내.
> "역별 자체 축으로 보면, 공유 축에서는 눌려 보이지 않던 변화가 더 잘 드러날 수 있습니다."

## 구현 방식

- 모든 계산은 클라이언트 사이드에서 현재 필터 상태(`selectedStations`, `dateRange`, `metric`, `includePandemic`)를 입력받는 순수 함수로 작성 (`lib/insights.ts` 같은 파일에 분리)
- 서버 호출 없이 이미 로드된 `dashboard_data.json`으로 전부 계산 가능
- React `useMemo`로 필터 상태가 바뀔 때만 재계산하도록 최적화 (2,794건 정도는 매번 다시 계산해도 성능 문제 없음)
- 문장은 하드코딩된 템플릿에 계산값만 채워 넣는 방식으로 충분 (자연어 생성 API 불필요)

## 주의사항 (이번 분석에서 배운 것 그대로 반영)

- 2025년 결측 구간을 건너뛰는 날짜 계산은 반드시 실제 `date` 값 비교로 처리 (배열 인덱스 기반 금지)
- 표본이 너무 적은 구간(예: 3개월 미만 선택)에서는 "데이터가 부족해 신뢰도가 낮습니다" 같은 경고를 자동으로 붙이기
